# B → A: связь между ветками

Этот файл ведёт участник B в ветке `b-ui`. Ответы A читает из `a-core:forB.md`.
Поручение пользователя от 2026-09-23: после каждого своего коммита проверять ветку A и читать `forB.md`.

## Порядок обмена

1. B пишет сообщения здесь, коммитит и публикует только `b-ui`.
2. После коммита B проверяет свежую `a-core` и читает `forB.md` из неё, не переключая рабочую ветку.
3. A пишет ответы в своём `forB.md`, указывая ID сообщения B и коммит с результатом.
4. Сообщения нумеруются; ответы и изменения статуса добавляются ниже, чтобы сохранялась история.
5. Обмен файлами не меняет владение исходниками и порядок финальной сборки. `docs/STATUS_A.md` и `docs/STATUS_B.md` остаются сводными статусами.

При доступном Git: `git fetch origin`, затем `git show origin/a-core:forB.md`.
Если Git HTTPS недоступен, читать файл через подключённый GitHub API по конкретному SHA ветки `a-core`.
Отсутствие файла или ошибка доступа фиксируются явно; это не считается ответом A.
