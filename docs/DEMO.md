# Пятиминутное демо для жюри

**Подготовленный сценарий.** Файл не подтверждает, что репетиция или выступление уже проведены.
Цель показа: от исходных переводов до понятной очереди проверки, границ выводов и выгрузки оснований.

## Перед показом

- Откройте репозиторий и окружение по [README](../README.md). Выберите реальные `data/` и `out/`, без отметки «ЗАГЛУШКА».
- В одном терминале подготовьте `python run.py --data data --out out`; во втором запустите `python -m streamlit run app.py`.
- Откройте приложение на «Топ-листе». В строке «Активные фильтры» проверьте: все 7 ролей, слой «Структура», 2248 узлов. Если условия отличаются, нажмите расположенную рядом кнопку «Сбросить фильтры».
- Рядом держите терминал и папку для скачивания XLSX. Конфигурация Streamlit запускает сервер без запроса email; откройте напечатанный локальный адрес вручную.
- Ключ OpenAI для этого сценария не нужен. Живой API-вызов не входит в обязательные пять минут.
- Перед выступлением сверьте карточки ниже с текущими [nodes_roles.csv](../out/nodes_roles.csv) и [top_nodes.csv](../out/top_nodes.csv). После изменения данных используйте свежие значения.

## Термины простыми словами

| Термин на экране | Как сказать жюри |
|---|---|
| **seed** | Один из 81 исходных клиентов, от которых собиралась сеть. Это стартовая точка анализа, а не найденный нашей моделью организатор. |
| **Роль / гипотеза** | Описание наблюдаемого поведения: сбор, распределение, транзит и другие признаки. Роль — повод для проверки. |
| **role_score / сила признаков** | Эвристическая оценка 0–1 по указанной формуле. Значение 0,80 не означает 80% вероятности преступления. |
| **priority / приоритет** | Место в очереди аналитика с учётом роли, денег, связности, объёма и времени. Не прогноз результата расследования. |
| **Маршрут по датам** | Цепочка существующих переводов с неубывающими датами и паузами не больше Δ. Внутридневной порядок неизвестен. |
| **Атрибутированный поток** | Осторожная модель: не-seed не пересылает больше учтённых средств от seed, чем получил. Она не доказывает, что по цепочке двигались те же деньги. |
| **Обрыв / неполная наблюдаемость** | Дальнейшие операции не попали в исходную выборку. На четвёртом колене отсутствие исходящих не является подтверждением удержания денег. |
| **Контр-сигнал** | Факт, ослабляющий простую интерпретацию: например, внешнее финансирование или неполные входящие seed. Его показываем вместе с аргументами за роль. |
| **Случайный сценарий устойчивости** | Среднее 100 воспроизводимых порядков удаления. Диапазон 5–95% показывает разброс исходов, а не доверительный интервал среднего. |

## Быстрые ответы на вопросы

- **Почему удаление out_deg сильнее разрушает граф, чем priority?** Первая стратегия выбирает по числу получателей; очередь проверок учитывает пять групп признаков. Она не оптимизирует блокировку. Фактический вклад связности в текущем топ-30 не превышает примерно 0,00249 до множителей: малое измеренное изменение графа даёт малый вклад, даже при весе 0,20.
- **Какой random показан на графике?** Среднее 100 случайных порядков с воспроизводимым генератором seed=42; диапазон — 5-й и 95-й процентили исходов. Нельзя пересказывать прежнее сравнение с одной случайной выборкой как результат этой серии.
- **Почему крупный распределитель может быть ниже топа?** Количество получателей — только один аспект. Важны наблюдаемый поток seed, роль и контр-сигналы. Флаг внешнего финансирования требует для не-seed одновременно `out_kzt/in_kzt>2` и `tracked_out_share<10%`; он снижает приоритет, но не устанавливает источник денег.
- **Скор payer=0,8 означает высокий риск?** Нет. Это фиксированный скор соответствия простому правилу небольшого разового плательщика. Его вес в приоритете низкий; роль не означает виновность.
- **5000 ₸ — порог банковского контроля?** В этом проекте это нижняя граница исходной выгрузки. Признак близости суммы к ней не доказывает дробление операций.
- **Что означает кластер?** Louvain группирует связи внутри слабосвязных компонент на неориентированной проекции с суммой весов обоих направлений. Номер кластера задан размером и не является оценкой риска. Направления переводов видны на графах и в путях.
- **Все опциональные пункты ТЗ реализованы полностью?** Есть временные признаки, маршруты, структурные циклы, устойчивость, карточки, ассистент и запросы данных. Повторяемость маршрутов, хронология циклов и отдельная модель аномалий относительно колена не заявляются; точная матрица есть в README.
- **Как проверить произвольный gid?** Вставить полный номер в поиск → открыть «Узел» → прочитать сводку → раскрыть критерии и показать соседей.
- **Что передаётся в OpenAI?** Только при включённом опциональном ассистенте — вопрос и выбранные сведения графа. Обязательный показ проходит без него.
- **Чего не видно в данных?** Других банков, сумм ниже 5000 ₸, полного баланса, времени внутри дня, личности и типа счёта; обход ограничен четырьмя коленами.
- **Где готовое решение?** Код, данные и выгрузки — в репозитории команды; установка и проверка — в README. Публичный deployment не заявлен.
