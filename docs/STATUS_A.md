## Решения, которые я принял сам

- Для A2 учёт переводов внутри одного дня сортируется по глубине отправителя, затем по gid; транзакции имеют только даты.
- `paths.csv` выбирает пути по максимальной минимальной сумме, затем по меньшему числу шагов; после A4 пересчитан для финального топ-30.
- Louvain применяется внутри слабых компонент к неориентированной проекции с весом `sum_kzt`; размер сообщества определяет порядок `cluster_id`.
- В A5 потеря seed-достижимости при удалении узла теперь включает сам удалённый узел, как буквально задано в 7.4. Порядок топ-30 не изменился.
- `run.py` сохраняет обязательные CSV при ошибке создания XLSX, но отмечает этап пропущенным и удаляет старый XLSX, чтобы не выдавать его за свежий.
- `docs/CODEX_A.md` и `docs/CODEX_B.md` появились локально без истории Git; не редактирую и не добавляю их в свой коммит.
