## Решения, которые я принял сам

- При отсутствии готовности A1 в статусе A приложение по умолчанию использует out_stub;
  папку out можно явно выбрать для read-only проверки.
- Не ждать необязательных колонок: отображать «нет данных», а не придумывать признаки.
- README содержит запуск, формулы, ограничения и схему. tools/update_readme_results.py обновляет цифры только при готовом A4; до него плейсхолдеры.
- Скриншоты сделаны на реальном A5. Неполные дополнительные CSV дают сообщение, а не падение всего приложения.
- Git HTTPS не авторизован; подключённый GitHub API позволяет публиковать b-ui без изменения main.
  Объекты Git при синхронизации проверяются по SHA; опубликованная история не переписывается.
