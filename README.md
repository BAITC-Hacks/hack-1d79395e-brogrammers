# Граф денег — рабочее место AML-аналитика

Поиск по gid, приоритеты проверки, карточка с объяснениями и направленный ego-граф.
Выводы — гипотезы для проверки, не установление вины.

## Запуск участника B

Python **3.11 или 3.12**. Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/make_stub_outputs.py --data data --out out_stub
GRAF_OUT=out_stub streamlit run app.py
```

Windows PowerShell: `.venv\Scripts\Activate.ps1`, затем
`$env:GRAF_OUT="out_stub"; streamlit run app.py`.
Откройте адрес, который напечатает Streamlit (обычно http://localhost:8501).

В sidebar можно сменить `out_stub` на предоставленную A папку `out`.
Без `GRAF_OUT` приложение выбирает `out`, если есть `out/nodes_roles.csv`, иначе `out_stub`.
Исходные parquet берутся из `data/`; другой путь задаётся в sidebar или через `GRAF_DATA`.
Поддерживается ZIP организаторов с папкой `data/` внутри. Генератор использует `graf.load.load`.

**Заглушка — только для разработки.** Степени, суммы, связи и пути взяты из parquet.
Роли, приоритеты, денежные следы и устойчивость демонстрационные (seed=42).
Это отмечено в интерфейсе, evidence и JSON-метаданных. Генератор не пишет в `out/`.

## B0/B1: что работает

- Все 13 файлов контракта §4 TEAM_PLAN: 2248 узлов, 3119 рёбер, 4840 исходных транзакций;
  в заглушке 20 кластеров, топ-30 и по 3 пути к каждому узлу топа.
- Топ заглушки выбирается из узлов с тремя реальными хронологическими путями, без
  зашитых gid. Это демонстрационная подборка, а не аналитическое ранжирование.
- Поиск по префиксу/полному gid, переход из строки топа в карточку, отдельный список seed
  для пересмотра уровня. Неизвестный gid вызывает понятное сообщение.
- Карточка: роль, уверенность, альтернатива, evidence, сигналы/контр-сигналы, компоненты
  приоритета, флаги, прослеживаемый поток, топ-5 входящих/исходящих, пути, кластер и запросы.
- Ego-граф на 1–2 шага: стрелки, цвета ролей, размер по приоритету, обводка seed,
  пунктир при неполной наблюдаемости. Физика выключена, ресурсы pyvis встроены без CDN.
- До 250 узлов в графе: ближайшие, затем по приоритету; сокращение явно отмечается.
  Признаки карточки относятся к полной выгрузке.
- gid хранится как int64, а в браузерных таблицах, JSON, pyvis и Plotly передаётся строкой.

Кэш загрузки учитывает изменение файлов. «Обновить выгрузки» сбрасывает кэш.
Отсутствующие дополнительные файлы перечисляются и не подменяются результатами анализа.

## Стыковка с a-core

Текущая база — A1, коммит `eb906662` ветки `a-core`. Ядро получено слиянием.
B не запускает `run.py`, не пересчитывает и не редактирует `out/`.
Готовый `out/` A1 используется только для проверки совместимости; разработка B — на `out_stub/`.

В A1 `graf.flow.chrono_reach` ещё выбрасывает `NotImplementedError`. До A2 доступны
только переданные `seed_exp_fast` (Δ=2) и `seed_exp_chrono` (Δ=31), с явной пометкой.
Нулевые колонки-заглушки A1 не доказывают отсутствия маршрутов.

У карты, XLSX, устойчивости и AI есть ранние заготовки из предыдущих коммитов;
полная приёмка этих разделов относится к B2–B4. Текущая проверенная поставка — B0/B1.
Основной интерфейс работает без API-ключа.

## Проверки

```bash
python tools/make_stub_outputs.py --data data --out out_stub
python -m pytest -q tests/test_ui_stub.py tests/test_ui_app.py
```

Проверяются схемы, 19 изолированных seed, точность соседних 18-значных gid,
направление рёбер, отсутствие CDN, реальные транзакции путей, даты, поиск и навигация.
UI-тесты используют Streamlit AppTest и не обращаются к LLM.

## Ограничения

Только внутрибанковские переводы от 5 000 ₸ за июль 2026. На глубине 4 исходящие
не собирались. Входящие извне сети неполны, особенно у seed; полный баланс неизвестен.
Даты без времени не устанавливают порядок переводов внутри дня. Близкие даты и связи
не доказывают движение одних и тех же денег. Флаг агрегатора — повод запросить АБС, не факт.
